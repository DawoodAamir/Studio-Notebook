# Contributing

Use Xcode 27 and the OS 27 SDKs. Keep changes focused and run Debug/Release core tests plus the relevant native build. UI changes should be checked on iPad and Mac with large text, VoiceOver, keyboard input, and Undo. Preserve format compatibility or add an explicit migration. Do not commit signing identities, local documents, build artifacts, or user data.

Use concise Conventional Commit messages. New fixtures must be original or have documented reuse rights.
