# Privacy

Notebook pages, notes, drawings, and recognised text are stored in the document selected or created by the user. This app has no server, account, analytics, or network client entitlement. PencilKit handwriting recognition runs locally.

Import grants access to the selected image while it is read. Export writes only the notebook or PDF selected by the user to their chosen destination. Cloud storage providers and destinations selected in the system interface have their own privacy policies. The app does not enable blanket Documents-folder file sharing.

Deleting a page supports Undo during its editing session. Removing a document uses the system document interface and its recovery behavior. Do not put sensitive material in public screenshots or test fixtures.
